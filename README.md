# react-native-fast-base64

A fast, JSI-powered drop-in replacement for atob/btoa with native C++ base64 encoding and decoding for React Native.

## Installation


```sh
npm install react-native-fast-base64
```


## Usage


```js
import { multiply } from 'react-native-fast-base64';

// ...

const result = multiply(3, 7);
```
